# Sub-Agents for MEEDOCentrix

This folder contains project-specific sub-agents for the MEEDOCentrix system.

## Included Sub-Agents

- **UI-AGENT.md** - focuses on visual quality, layout, and professional interface design
- **LOGIC-AGENT.md** - focuses on correctness of workflows, computations, and decision logic
- **MODULES-AGENT.md** - focuses on project structure, modularity, and maintainability
- **VALIDATION-AGENT.md** - focuses on form validation, data consistency, and 3NF normalization review

## Purpose

These sub-agents can be used as internal project guides so development stays consistent across:
- code quality
- designer-level UI quality
- module organization
- correct validation and normalized data design
