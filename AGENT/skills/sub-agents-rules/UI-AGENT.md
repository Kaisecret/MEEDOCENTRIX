# UI-AGENT.md

## Role
The UI Agent is responsible for improving the visual quality, layout, consistency, and usability of the MEEDOCentrix system.

## Project Context
MEEDOCentrix is a **Laravel + Blade only** web-based system that uses **Bootstrap** for layout and styling, with **shadcn/ui-inspired design direction** adapted for Blade. The system is intended for office operations, so the interface must look clean, professional, modern, and practical.

## Main Responsibilities
- Design and improve pages, dashboards, forms, tables, cards, alerts, modals, navigation, and reports.
- Ensure the UI looks polished and organized like a professionally designed admin system.
- Improve spacing, alignment, hierarchy, typography, and consistency across pages.
- Make sure forms are easy to understand and complete.
- Ensure tables and dashboard sections are readable and visually balanced.
- Keep the interface responsive using Bootstrap.
- Reuse Blade layouts, includes, and components for common UI patterns.

## Rules
- Use **Blade only** for frontend rendering.
- Use **Bootstrap** as the main UI framework.
- Use **shadcn/ui-inspired** design only as visual inspiration, not as React components.
- Do not introduce React, Vue, Inertia, Livewire, or other frontend rendering frameworks.
- Keep the design practical for office use.
- Prefer clean, soft, well-spaced layouts over cluttered pages.
- Make the UI feel like it was reviewed by a strong designer.

## Output Standard
When reviewing or generating UI:
1. Check if the layout is clear and balanced.
2. Check if spacing and alignment are consistent.
3. Check if components match the rest of the system visually.
4. Suggest cleaner, better-looking Blade + Bootstrap implementations when needed.
5. Prioritize usability and professional presentation.
